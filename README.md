# Review RDK Logger

Web UI and CLI for reviewing RDK log bundles (`<MAC>_Logs_<MM-DD-YY-HH-MMAM>.tgz`).

- Groups bundles by device MAC and capture time
- Lists every log in a bundle, including rotated logs (`PAMlog.txt.0`, `csc_mon.log.1`, ...)
- Counts errors/warnings per file (`ERROR`, `PANIC`, `FAIL`, `EXCEPTION`, `WARN`, ...)
- Side-by-side viewer (up to 4 panes) with search, severity filters, jump-to-next-error and download
- Drag-and-drop upload, light/dark theme, shareable URLs

## Install

Pick the option that fits. Every installer is safe to re-run; re-running is how you update.

### Linux server (systemd)

```bash
curl -fsSL https://raw.githubusercontent.com/udaybhadauria/Review_LogFiles/main/install_review_rdklog.sh | bash
```

This installs OS packages (git, python3, venv), clones the repo to `~/Review_LogFiles`, creates a
virtualenv, writes `.env` with a random secret, installs the `review-rdklog` systemd service
(gunicorn, HTTPS) and waits until `/healthz` responds.

```bash
# custom location / port, open the firewall
curl -fsSL https://raw.githubusercontent.com/udaybhadauria/Review_LogFiles/main/install_review_rdklog.sh \
  | bash -s -- --dir /opt/review_logfiles --port 8443 --open-firewall

bash ~/Review_LogFiles/install_review_rdklog.sh --status      # version, service state, health
bash ~/Review_LogFiles/install_review_rdklog.sh               # update
bash ~/Review_LogFiles/install_review_rdklog.sh --uninstall   # remove
```

| Option | Meaning |
| --- | --- |
| `--dir PATH` | Install directory (default `~/Review_LogFiles`) |
| `--repo URL` / `--branch REF` | Source repository and branch/tag |
| `--host ADDR` / `--port N` | Listen address / port (stored in `.env`) |
| `--no-service` / `--service` | Skip / force the systemd service |
| `--open-firewall` | Open the port in ufw or firewalld |
| `--skip-packages` | Don't install OS packages |
| `--status` | Show installed version, service state and health |
| `--uninstall [-y]` | Remove the service (and optionally the directory) |

Supported package managers: apt, dnf, yum, zypper, apk, pacman, brew. Requires Python 3.10+.

### Windows (local)

```powershell
irm https://raw.githubusercontent.com/udaybhadauria/Review_LogFiles/main/install_review_rdklog.ps1 | iex
```

Then start it with `%USERPROFILE%\Review_LogFiles\start_review_rdklog.cmd` and open https://localhost:5001.
Options when running the script directly: `-Dir`, `-Repo`, `-Branch`, `-Port`, `-Start`, `-Uninstall`.

### Docker

```bash
docker compose up -d --build        # https://<host>:5001, data kept in the review-data volume
```

### From a source checkout (development)

```bash
python -m venv .venv && . .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
review-rdk-web --dev                            # or: python app.py
python -m pytest -q
```

## Configuration

Runtime files live in the data directory: `$REVIEW_DATA_DIR`, or the current directory
(the installers point it at the install directory). It holds `.env`, `uploads/` and `certs/`.

| Setting (`.env`) | Default | Meaning |
| --- | --- | --- |
| `APP_HOST` / `APP_PORT` | `0.0.0.0` / `5001` | Listen address and port |
| `APP_SSL` | `1` | `0` serves plain HTTP (e.g. behind a TLS-terminating proxy) |
| `SSL_CERT` / `SSL_KEY` | `certs/*.pem` | Your own certificate; a self-signed one is generated otherwise |
| `FLASK_SECRET_KEY` | random | Generated by the installers |
| `ARCHIVE_DIR` | data dir | Extra folder scanned for `.tgz` bundles (`uploads/` is always scanned) |
| `MAX_UPLOAD_MB` | `500` | Upload size limit |
| `WEB_WORKERS` / `WEB_THREADS` | `2` / `4` | gunicorn workers/threads (Linux) |

`review-rdk-web --help` lists the command-line overrides (`--host`, `--port`, `--no-ssl`, `--dev`).

## CLI

```bash
review-rdk-logger .                                       # every .tgz in a directory
review-rdk-logger 00CB7AC3E122_Logs_11-01-26-04-37PM.tgz --output reports/report.json
```
